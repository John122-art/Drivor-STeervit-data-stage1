## 已修复

`stage2/validate.py`原先直接比较原始GT框数组和JSON列表。空数组`(0,7)`序列化为
`[]`后，读取的形状是`(0,)`，会被误判为GT不一致，导致整个任务停止。
此问题用空数组回归用例复现；现在仅为这种空数组恢复丢失的形状。
非空框的数量、形状和值仍严格比较。没有声称在本次真实三场景中遇到了空GT。

新增空GT、非空GT拒绝错误数据、8分片合并和跨分片重复token拒绝测试。
第一阶段16个原有Python文件的SHA256均与修改前快照一致。
提示词、128-token清理规则、单相机独立回退、模型调用次数均未修改。

指令为单机8卡离线数据处理，依次生成train、val、test。
`SCENES_PER_RANK=0`表示每片所有原生有效场景；`DEEP_SCENES=20`只限制额外重投影检查的数量。
没有启动全量任务。本机只有一张可见设备，8分片合并测试及dry-run不等于8卡模型实跑。

`stage2_navigation_no_rewrite_v2_8gpu_pilot`均不存在，可作为新任务目录。
